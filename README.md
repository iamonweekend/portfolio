# Vansh — Personal Portfolio

A personal developer website designed with an authentic early-web / retro aesthetic. Built with strict monochrome contrast, thick black graphic borders, boxed browser-style modules, and chunky typography.

---

## ✦ Design System & Visual Characteristics

- **Aesthetic**: Early-2000s web & retro computer interfaces meets modern web engineering.
- **Palette**: Strict monochrome light mode (`#000000`, `#FFFFFF`, `#F5F5F0`, `#D9D9D4`, `#333333`).
- **Typography**: Space Grotesk (chunky headlines) & Space Mono (interface details, numbers, logs).
- **Graphic Borders**: 2px/2.5px solid black borders with hard drop shadows (`3px 3px 0 #000000`, `4px 4px 0 #000000`).
- **Boxed Modules**: Browser-style window title bars with retro dot controls.

---

## ✦ Structure

1. **Retro Navigation**: Simple centered rectangular box with equal-width links (`Projects`, `Experience`, `About`, `Find Me`).
2. **Hero Section**: Chunky personal introduction, CTA, and original monochrome retro computer line art.
3. **Selected Projects**:
   - `01 bambukatharyanvi.com` — Website / Web Development (2026)
   - `02 sjwpmultiservices.com` — Website / Web Development (2026)
4. **Experience Section**: Factual log of 2 years of building on the web across freelance client projects and web development work.
5. **About Section**: Centered retro boxed profile with bio, role (`Frontend Developer`), and location (`Haryana, India`).
6. **Find Me**: Direct communication channels (GitHub: [iamonweekend](https://github.com/iamonweekend), LinkedIn, Gmail: `iamonweekend@gmail.com`).
7. **Footer**: Clean, spacious centered colophon.

---

## ✦ Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
